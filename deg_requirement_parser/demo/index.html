The students are made up. None of them is a real person and no course list comes from a real STARS report. Their verdicts were worked out ahead of time by the project's Python solver (bip.py), the same one the golden-case checks use. This page only displays them.

Not an official USC source. The trees were written by an LLM from the catalogue text and checked for shape and citations, not reviewed line by line. See deg_requirement_parser/README.md, “Where it might be wrong”.
